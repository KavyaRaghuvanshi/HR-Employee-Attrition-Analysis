# HR Employee Attrition Analysis

## 📌 Project Overview
This project analyzes employee attrition data to identify key factors influencing why employees leave a company.

## 🛠 Tools & Technologies
- Python
- Pandas
- RandomForest
- Seaborn
- train_test_split
- Matplotlib
- Confusion Matrix
- Jupyter Notebook

## 📊 Key Steps
- Data Cleaning (handling missing values)
- Exploratory Data Analysis (EDA)
- Data Visualization (box plots, count plots)

## 🔍 Key Insights
- Employees working overtime are more likely to leave
- Low job satisfaction increases attrition
- Work-life balance impacts employee retention

## 📁 Files
- `Employee Attrition Analysis.ipynb` – Main notebook
- `HR_Attrition_Risk_Report.csv` - CSV File created of Report
- `HR_Employee_Attrition.csv` – Dataset used

## 🚀 Conclusion
This project demonstrates how data analysis can help organizations reduce employee attrition and make better HR decisions.
